# GramaAngana

GramaAngana is an Android application developed for community management and local village services.

## Features
- User/Admin Login
- Booking Management
- Maintenance Requests
- Events Display
- Calendar View

## Technologies Used
- Kotlin
- Android Studio
- XML
- Room Database

## Frontend
Designed using XML layouts with modern UI screens.

## Backend
Implemented using Room Database for local data storage.
